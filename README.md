# 即梦本地管理台

临时海扇迁移脚本见同目录 `MIGRATION.md`：按「剧名简称-人设/场景/道具-名称」导入已导出素材，默认仅预览，明确执行才上传。

功能优先的本地工具。Python 标准库 + SQLite + 原生网页，无 npm 依赖、无公网部署。

## 启动

独立视频资产目录：双击 `start-assets.cmd`，打开 <http://127.0.0.1:8768/>。它只运行本地目录，不调用CLI、不触碰原画布队列；数据在 `%USERPROFILE%\.dreamina-video-assets`。原画布管理继续使用下面的8765入口。更新后原管理台需重启Python服务才会启用同页资产模块，单刷新网页不足以更新后端。

双击同目录 `start.cmd`，或在 PowerShell 执行：

```powershell
& 'C:\Users\EDY\Documents\ChatGPT\即梦\start.ps1'
```

然后打开 <http://127.0.0.1:8765>。启动脚本优先使用 Codex 自带 Python；亦可用 Python 3.11+ 运行 `manager.py`。

端口占用可用 `start.ps1 -Port 8766`。同一数据目录只允许一个实例。不要将服务转发到公网。

## 第一版功能

- 独立“视频资产”目录：只接受官方生成历史视频页已读取/导入的详情，按提示词开头的剧名分组，识别不出的放“其他”；不拿画布节点替代。
- 支持项目筛选、提示词搜索、本地剧名/简称配置、JSON清单导入导出。自动识别开头 `《剧名》`；无括号时需已登记简称和分隔符，如 `浪子回头-第1集`。
- **视频资产目录目前不是官方全量自动同步**：官方CLI没有该资产列表命令。已读取的详情可以由Agent导入或使用JSON清单；未读取的视频不会出现。
- **资产内嵌预览**：列表点击“预览”，对已接入的临时官方播放源直接使用原生播放器；未接入时可让Agent读取对应官方详情的可见视频元素，或自行接入同一视频的播放源。只允许已核对的v3/v26-artist.vlabvod.com域名，无后端代理、无私有接口。地址仅保存在当前网页内存，不进入API、数据库、导出或本地存储；刷新即清除，过期需重新读取。播放失败会提示，不自动重试或提交生成。也可选择已下载的本地视频预览，不上传。下载仍在官方页面进行。
- 同一JSON清单重复导入不增加记录；不同清单没有官方稳定资产ID，不能保证跨批次去重。导出时保留的 recordId 是本地UUID，更新原记录请沿用它。
- 清单格式：`{"source":"jimeng-official-video-page","items":[{"prompt":"《浪子回头》-第1集……","date":"2026-10-14","duration":"25s","model":"页面实际模型","resolution":"页面实际分辨率","ratio":"16:9"}]}`。每批1–500条、最多2MiB。不接受Cookie、Token、播放URL或画布节点字段。

- 检查 CLI 版本、登录与账户；未登录可发起官方设备授权，后台等待。
- 分页查询画布，明确选定目标；不会修改 CLI 默认画布。
- 视频与主体节点列表、搜索、视频状态筛选、节点详情、提示词与关联素材。
- 本地备注（不写入远端）、下载队列、成功下载后的浏览器预览和保存。
- 多图或文件夹导入，按直接父目录分组，调整分组与主图，填写主体描述。
- 图片先暂存本机；点击并确认后才上传到即梦。每组创建图片来源节点，再建立主体，保留上游关系。
- SQLite 持久队列，单线程按序执行、逐项记录标识、回读验证主体绑定。
- 失败/中断手动恢复；成功阶段不重复执行。相同画布、名称、描述和有序素材内容复用原任务。
- 可暂停尚未开始的单项或全部队列；不能取消已发送到服务端的操作。
- 导出非敏感恢复标识。未提交分组草稿只在页面内存中，刷新会丢失；已提交队列不会丢失。

## 使用顺序

1. 检查账号，选择目标画布；没有画布时先用官方 CLI 或即梦页面创建。
2. 在“批量上传主体”选择图片或文件夹。
3. 同一个分组名称代表一个主体。指定主图，其余图片为辅助图；目录名称不一定适合作主体标题，请检查。
4. 点击上传并核对目标画布。第一版只接受图片主体，不自动生成辅助图或音色。
5. 在任务队列查看每组进度；暂停时先看错误和 requiredAction，再恢复原任务。
6. 刷新主体列表，并在原画布检查内容。

## 下载与视频边界

当前已核对的 CLI 1.0.2 schema 中 `resource download` 摘要只声明图片下载，不能保证视频或音频可下载。
页面提供“请求 CLI 下载”，严格使用公开命令，由实际返回决定；拒绝时显示错误并保留画布入口，不抓取私有地址或绕过限制。
只有下载成功、路径/大小/SHA256 校验通过的本地文件才提供预览。浏览器还可能不支持某些视频编码。
没有产物的视频节点仅可查看设置，不能播放。此工具不负责生成、剪辑、删除或取消远端任务。

## 数据与安全

- 默认数据在 `%USERPROFILE%\.dreamina-manager`：数据库、本地暂存图片、下载文件、实例锁。固定使用用户主目录，避免 Codex 打包环境的 AppData 虚拟化导致普通终端看不到原队列。
- 仅监听 127.0.0.1；校验 Host、会话 Cookie、Origin 和 CSRF，不允许跨站操作。
- 使用参数数组执行固定 CLI 命令，不使用 shell 拼接；禁止 `--run`、积分确认参数及任意命令执行。
- 所有远端操作显式绑定项目；登录凭据仍由官方 CLI 保管，授权 challenge 仅保存在内存。
- 不将原始 CLI 输出写日志，不持久化签名地址、token 或内部存储标识。
- 上传收到响应后还检查资源状态，节点保存后回读；结果不确定时暂停，不自动循环重试。
- 服务未返回成功上传响应时，恢复先用原资源标识查询；无法确认则仍暂停，避免重复上传。
- 不做自动文件清理；长期使用需关注暂存和下载占用。备份数据库时先停止程序，将整个数据目录备份到私人位置。
- 会话只防跨站访问，不防本机恶意程序；不要在共享账号或不可信环境中运行。
